# Quote Generator

A simple **Quote Generator** built with **HTML, CSS and JavaScript**.

Generate a random quote with a single click and get inspired by motivational quotes.

## Features

* Generate a random quote
* Responsive design
* Simple UI

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/devjayosch/QuoteGenerator.git
```

### 2. Open the project

Open the project folder in **Visual Studio Code**.

### 3. Run the website

Open `index.html` in your browser.

That's it! 🎉
